# **Motorola Mobile Sales Dashboard 📊**

## Project Overview
This Power BI project analyzes mobile sales data to understand sales performance, customer behavior, payment methods, and product performance across different cities and time periods.

## Tools Used
- Microsoft Power BI
- DAX
- Power Query
- Data Visualization

## Key KPIs
- Total Sales: ₹769M
- Total Quantity: 19K
- Total Transactions: 4K
- Average Sales: ₹40K

## Dashboard Analysis
- Total Sales by City
- Monthly Quantity Trends
- Customer Ratings
- Transactions by Payment Method
- Brand-wise Sales & Quantity
- Mobile Model Performance
- Day-wise Sales Analysis
- Monthly Filtering

## Key Insights
- Analyzed sales performance across different Indian cities.
- Compared sales and quantity across mobile brands and models.
- Analyzed customer ratings to understand customer satisfaction.
- Studied payment preferences such as UPI, Debit Card, Cash and Credit Card.
- Identified monthly and day-wise sales trends.

## Skills Demonstrated
- Data Cleaning
- Data Modeling
- DAX
- Power BI Dashboard Design
- Data Analysis
- Data Visualization
- Business Insights


# 🛒 **Amazon Sales Dashboard – Power BI**

An interactive Amazon Sales Dashboard built using Microsoft Power BI to analyze product categories, ratings, prices, discounts, and product performance.

## 📊 Dashboard Overview

This dashboard provides insights into:

- Total Products
- Average Rating
- Average Price
- Average Discount
- Top Product
- Products by Category
- Rating by Category
- Rating by Product
- Category-wise analysis using filters

## 🛠️ Tools & Technologies

- Power BI
- Power Query
- DAX
- Data Cleaning
- Data Visualization

## 📌 Key Insights

- Identified the most represented product categories.
- Analyzed product ratings across different categories.
- Compared product ratings to identify top-performing products.
- Analyzed average price and discount percentage.
- Created an interactive dashboard with category filters.

## 🎯 Objective

The objective of this project is to analyze Amazon product data and create an interactive Power BI dashboard that helps understand product performance, ratings, pricing, and discounts.


# HR Analytics Dashboard | Power BI

## Project Overview
This HR Analytics Dashboard is created using Microsoft Power BI
to analyze employee data and understand HR performance.

## Key Insights
- Employee attrition analysis
- Employee distribution by gender
- Job satisfaction analysis by job role
- Years at company by job role
- Performance rating by job role
- Monthly income analysis
- Employee distribution across cities

## Tools Used
- Microsoft Power BI
- Data Visualization
- Data Analysis

## Dashboard Features
- Interactive job role filters
- Attrition and overtime employee KPIs
- Donut charts for HR metrics
- Bar chart for years at company
- Employee details table
- Geographic visualization

## Objective
The objective of this project is to help HR teams understand
employee trends, job satisfaction, performance, and attrition
through interactive visualizations.
